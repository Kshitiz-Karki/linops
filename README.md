# LINOPS

My personal dotfiles and packages installer on top of a fresh fedora sway spin.

## Requirements

Ensure you have the following installed on your system:
  - wget
  - git

## Installation

Install fedora sway spin, then:

```
wget -qO- https://raw.githubusercontent.com/Kshitiz-Karki/linops/refs/heads/main/install.sh | bash
```

## Why sway spin and not Fedora Everything/Minimal ISO?

The installer has best out of the box support for:
  - sway & related packages
  - re-install of the OS keeping the home directory as-is
